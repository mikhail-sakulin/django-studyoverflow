Математические формулы через LaTeX

Для отображения математических выражений используйте специальные HTML-теги. Запись через $...$ и $$...$$ недоступна. Введенный текст на сервере очищается от неразрешенных HTML-тегов и их атрибутов через библиотеку bleach, обеспечивая безопасность.

1) Формула внутри текста:

<span class="math-inline">\mu</span>

Результат:

\mu

2) Отдельная формула по центру:

<div class="math">\sigma = \sqrt{\frac{1}{n}\sum_{i=1}^{n}(x_i-\mu)^2}</div>

Результат:

\sigma = \sqrt{\frac{1}{n}\sum_{i=1}^{n}(x_i-\mu)^2}

Внутри этих тегов используется синтаксис LaTeX, например: \alpha → \alpha, \beta → \beta, \sqrt{x} → \sqrt{x}.

Обычный символ $ писать можно — например, $100 не будет считаться формулой.

3) Списки и задачи (ul, ol, вложенные списки, inline-код, ссылки)

Между заголовком списка и пунктами, а также между вложенными списками должны быть пустые строки.

Список:

1. Первый элемент
2. Второй элемент

   * Вложенный маркированный список
   * Инлайн-вставка `кусочка кода`
   * Обычная [ссылка](https://example.com "Подсказка ссылки")

- [x] Первый отмеченный пункт
- [x] Второй отмеченный пункт
- [ ] Неотмеченный пункт

Результат:

Список:

  1. Первый элемент
  2. Второй элемент
    • Вложенный маркированный список
    • Инлайн-вставка кусочка кода
    • Обычная ссылка
  • Первый отмеченный пункт
  • Второй отмеченный пункт
  • Неотмеченный пункт
